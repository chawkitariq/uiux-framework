# Roles

| Role | Model | Mission | Deliverable |
|---|---|---|---|
| Reference auditor | strongest | measure a reference site | numeric audit |
| Page architect | strongest | structure, scale, conventions | page plan |
| Premium copywriter | strongest | all public text | content file |
| Compliance guardian | mid | absolutes, commitments, banned terms | ready-to-paste fixes |
| Motion UI/UX designer | strongest | animation score | numeric spec |
| Foundations developer | mid | build, tokens, animation engine | skeleton + conventions |
| Section developers (xN) | mid | 1-2 sections each | their own files only |
| Critical art director | strongest | ruthless review on captures | 15 prioritised points |
| Cross reviewer | mid | design + marketing, economical | at most 8 points |
| Technical SEO specialist | mid | tags, structured data, perf (`technical-seo` skill and `seo-specialist` agent, see dev-framework) | files + control script |

## Short brief template (every role)
```
Goal: <one sentence, observable outcome>
Inputs: <files / spec / copy file to read first>
Your files (touch nothing else): <list>
Contracts to keep: <conventions, tokens, validated sections that are untouchable>
Deliverable: <exact format>
Check yourself with: <capture command + visual criterion>
Do not commit, push or deploy. Report unverified points honestly.
```
